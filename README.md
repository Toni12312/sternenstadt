# 🌟 Sternenstadt

Ein Bau- und Spielspiel für Kinder, ohne Werbung und kostenlos.
Häuser bauen und einrichten, eigene Figuren erfinden, Tiere, Tag und Nacht.
Die Spielzeit ist eingebaut: 30 Minuten am Tag.

## Spielen

Wenn GitHub Pages eingeschaltet ist, läuft das Spiel unter:

**https://toni12312.github.io/sternenstadt/**

## Als App auf dem Android-Tablet installieren

1. Die Adresse oben in **Chrome** öffnen.
2. Oben rechts auf **⋮** tippen, dann auf **„App installieren“** oder **„Zum Startbildschirm hinzufügen“**.
3. Sternenstadt hat jetzt ein eigenes Symbol, startet im Vollbild und läuft auch ohne Internet.

## Stadt von einem anderen Gerät mitnehmen

Startbildschirm → **💾 Spielstand übertragen** → auf dem alten Gerät „Code kopieren“, auf dem neuen Gerät einfügen und „Stadt laden“ tippen.

## Dateien

| Datei | Wozu |
|---|---|
| `index.html` | das ganze Spiel |
| `manifest.webmanifest` | Name und Symbol der App |
| `sw.js` | Offline-Speicher, damit das Spiel ohne Internet startet |
| `icon-*.png` | App-Symbole |
